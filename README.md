# Fichas de Seguridad - Curtiduria Tungurahua

Sistema de gestion de fichas de seguridad para productos quimicos, conectado a una base de datos Oracle (iDempiere).

## Instalacion

```bash
# Instalar dependencias
npm install

# Iniciar en modo desarrollo
npm run dev
```

Crear archivo .env.local con las especificaciones que estan en .env.example
